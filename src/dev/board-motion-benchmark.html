Method and limits
  • This page fetches the exact locally extracted board JSON at /__fixture/board.json. Only its text objects are rendered; content and world geometry are unchanged. Images are excluded from this text-renderer comparison.
  • 32 subpixel phases span 31/32 of one physical pixel on each axis inside the largest dense textbox, obj-545. Pixel readback crops a 24 CSS-pixel inset. Every phase preserves its row-mean brightness signal in JSON. At zooms where textbox edges enter the crop, measurements include the edges and are labeled accordingly.
  • Row contrast measures the RMS variation of horizontal mean brightness across image rows. Its variation over pan phases detects broad coherent striping missed by integrated ink totals. Adjacent-frame and second temporal difference RMS also include legitimate translation and 8-bit readback quantization; they are comparative diagnostics, not a proof of zero flicker.
  • Alias-band analysis uses the actual 24-world-pixel line pitch. A least-squares fit separates DC, a slow brightness trend, the legitimate line harmonics, and the first harmonic above the physical-pixel Nyquist limit. Per-phase spatial fits are marked unidentifiable when an alias coincides with a legitimate harmonic. A joint space/phase fit additionally distinguishes their temporal phase rotation during vertical panning. Both use orthogonalized least squares to limit finite-window leakage from the dominant line pattern. These fits estimate coherent periodic alias energy; nonperiodic content, other higher harmonics, and quantization remain in the residual.
  • Performance visits each real textbox with live object culling and getTextLayoutForViewport on each frame. Four alternating 60-frame blocks provide 120 measured frames per renderer. CPU submission includes culling, layout, and rendering; rAF timing includes scheduling. GPU execution is measured separately with EXT_disjoint_timer_query_webgl2 where supported, using asynchronous polling without waits or fences; unavailable, unresolved, or disjoint results are reported explicitly. Readback and PNG capture occur outside timed blocks.
  • Run all covers app-supported zooms 10%, 12.5%, 15%, 20%, 25%, 50%, and 100% at DPR 1 and 2. Native before/after PNGs save through the local evidence endpoint after measurements.
  • Measure zoom holds the center of the largest textbox fixed while zooming logarithmically from 10% to 100% and back, 120 frames in each direction. Its four blocks use previous/current/current/previous order. The first pass clears each renderer's text cache; the repeated pass preserves it. Fonts and text layout are loaded before measurement. Every frame records CPU time, independent GPU time, zoom, visible text, glyph submissions, and tile activity. Use ?width=1200&height=800 for a full-size backing workload; the default phase panels remain 400 by 256 CSS pixels.
  • Verify pixels compares exact RGBA readbacks outside timing at 14 zooms, including both sides of the 12-physical-pixel filter cutoff for DPR 1 and 2. Each zoom has four diagonal pan phases around the textbox center and four around a viewport edge aligned with the content's x = 1024 world-pixel bin boundary. Results separate the 24 CSS-pixel edge strip from the interior, reporting differing pixels, largest 8-bit channel difference, and RMS channel difference. JSON contains all 112 comparisons; PNG links show the final selected reference view.
  • Add ?baseline=1 when the fixture server supplies the baseline gpu-motion-before.js route. Without it both panels use the current renderer and comparison is labeled unavailable. Optional ?budget=0 forces the cache-pressure path. ?portable=1 disables optional floating-point extensions on both panels for a matched portable-path comparison. Optional ?cache=0 sets textTileCache: false only on the current renderer; the cache checkbox reloads this setting.
