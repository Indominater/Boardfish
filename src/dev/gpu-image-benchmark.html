Method and limits
  • Sources are prepared ImageBitmaps before any timing. Quarter sources contain one quarter of each original dimension. Object dimensions are chosen so the quarter/full boundary is 70.71% at the selected DPR.
  • Application viewport cropping is enabled by default through the actual Boardfish renderer. The optional uncropped stress case submits whole images. The pressure fixture exceeds the old GPU renderer's 128 MiB budget at full resolution. Native density cannot reduce retained image resolution.
  • Each renderer warms both source choices, then runs two measured blocks. Renderer order reverses in the second block. CPU submission and requestAnimationFrame intervals are separate metrics. No screenshot, readback, GPU finish or synchronization occurs inside measured frames.
  • Raster image differences include browser resampling filters; a numerical pixel difference is not alone a visual-quality verdict. Inspect the unscaled PNGs for seams, crop edges, flips and translucent overlaps.
  • The optional baseline file loads only with ?baseline=1. Create it with git show 5841044:src/js/gpu_renderer.js > src/dev/gpu-image-renderer-before.js, then delete it after comparison. Current GPU and Canvas2D remain runnable without it.
