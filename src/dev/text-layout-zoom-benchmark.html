Method
  • The fixture server supplies the unmodified text and geometry of obj-545 from boardTest.bf. The page uses the actual Geist font and the production text layout functions. No GPU rendering is involved.
  • Each run creates a fresh object and clears measurement caches. Auto-height preparation constructs the exact wrapping index; its time and work are reported separately.
  • 80 animation frames request visual rows 100–104, then extend the end by one row each frame. This isolates the progressively exposed rows encountered while zooming out through a partially populated textbox.
  • Light wrappers count paragraph characters passed to the wrapping function and bytes returned by the prefix-slice function. Timed layout calls include these wrappers equally in both versions. Animation frame intervals include browser scheduling and are reported separately from layout CPU time.
  • A full layout generated after timing verifies every requested row’s text, offsets, prefix widths, caret boundaries, and position. Its SHA-256 checksum is included for comparison between separate baseline and current pages.
  • Add ?baseline=1 to load the fixture server’s previous text layout source. Results save to the local evidence endpoint after timing.
