# Code of Conduct

## Our Pledge

We want Boardfish discussions to be useful, direct, and respectful. Everyone
participating in this project is expected to treat other people with courtesy
and to focus criticism on ideas, code, behavior, and product decisions rather
than personal attacks.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent when asking for clarification.
- Keep issues and pull requests focused on the project.
- Give enough context for others to understand and reproduce problems.
- Accept maintainers' decisions about project scope and licensing.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Sexualized language or attention.
- Publishing private information without permission.
- Repeated off-topic, promotional, or disruptive comments.
- Bad-faith arguments about licensing, project ownership, or maintainer intent.

## Enforcement

Project maintainers may edit, hide, or delete comments; close issues or pull
requests; block users; or take other reasonable action when behavior harms the
project or its contributors.

If you need to report a conduct issue, open a GitHub issue with the relevant
context. If the issue involves sensitive information, include only the minimum
detail needed to start the conversation.

## Scope

This code of conduct applies to project spaces including GitHub issues, pull
requests, discussions, and any other official Boardfish community spaces.
